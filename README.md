# Tic Tac Toe

A simple two-player Tic Tac Toe game that runs in the browser. No installation or internet connection required.

## How to Play

1. Open `tictactoe.html` in any web browser
2. The game is played by two players on the same device — **X always goes first**
3. Players take turns clicking an empty cell to place their mark
4. The first player to get **3 in a row** (horizontally, vertically, or diagonally) wins
5. If all 9 cells are filled with no winner, the game is a **draw**
6. Click **New Game** to reset the board and play again

## Scoring

The scoreboard tracks wins for X, wins for O, and draws across rounds. Scores reset only when you refresh the page.
